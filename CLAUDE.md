# CLAUDE.md

Служба Windows на mihomo (TUN): через прокси из подписки идут только `Claude.exe`/`claude.exe` и порт 7890,
российские сайты всегда напрямую. Устройство, файлы и настройки описаны в README.md, здесь только то, что
из кода не видно сразу.

## Осторожно: служба работает на этой машине

- Через неё идёт трафик самого Claude. Не останавливайте и не перезапускайте службу,
  не заменяйте `core\mihomo.exe`/`mihomo-service.exe` (файлы заняты) без просьбы пользователя.
  Ошибка в `tun` или правилах может оборвать связь.
- Правки конфига проверяются так: `core\build-config.ps1` (собирает и прогоняет `mihomo -t`),
  затем `core\reload.ps1 -Action Config` (перечитывание через API, без перезапуска).
  Проверка трафика: `curl -x http://127.0.0.1:7890 https://www.gstatic.com/generate_204` → 204.
- API без пароля на `127.0.0.1:9090`: `/providers/proxies`, `/proxies/proxy` и т.д.
  Подписки — это провайдеры с `vehicleType == HTTP`; встроенный `default` (Compatible) к ним не относится.
- Если для теста меняете `subscription.txt` или `core\config.yaml`, сначала сохраните копии в scratchpad,
  потом верните их и перечитайте конфиг. Служба должна остаться в том же состоянии.
  Лишние файлы в `core\providers\` после теста удалите.

## Секреты

- Ссылка на подписку (`subscription.txt`, `core\config.yaml`, `core\providers\`) — секрет.
  Не выводите её в чат и в лог команд: маскируйте, например `sed -E 's#(url: ")[^"]*#\1<скрыто>#'`,
  показывайте только хост. Скрипты фильтруют её из вывода `mihomo -t`, это поведение нужно сохранять.

## PowerShell-скрипты (core\*.ps1)

- Целевая версия — Windows PowerShell 5.1. Никаких `??`, `?.`, тернарного оператора, `&&`.
- Файлы `.ps1` в UTF-8 **с BOM** и с CRLF (см. `.gitattributes`). Без BOM PS 5.1 читает кириллицу
  как ANSI и скрипт ломается. После записи файла целиком проверьте `head -c3 файл | xxd -p` → `efbbbf`.
- Ответы API читаются через `Net.WebClient` с `Encoding = UTF8`, а не `Invoke-RestMethod`:
  тот в 5.1 портит кириллицу и эмодзи в именах серверов.
- Имена переменных не зависят от регистра: `$all` — это тот же параметр `-All` в status.ps1 (уже ловили).
- Сервер ищется по имени в `/providers/proxies`: имя с эмодзи в пути `/proxies/<имя>` mihomo не находит.
- Стиль: сообщения и комментарии по-русски, ошибки через `throw` внутри `try`, в конце `exit 0/1`.

## Шаблон и сборка конфига

- `build-config.ps1` размножает блок `proxy-providers.sub` текстом: блок идёт от строки `  sub:`
  до первой строки с отступом не больше двух пробелов. Ссылка подставляется только в `"SUBSCRIPTION_URL"`
  в кавычках. Подписки 2+ получают имена `sub2`..., путь `providers/subN.yaml`, а `use: [sub]` группы
  расширяется. При нескольких ссылках к именам серверов добавляется `additional-prefix: "[N] "`
  внутрь существующего `override:`. Не переходите на YAML-якоря: слияние `<<:` неглубокое, и
  `override-expr` (исправление gRPC `//Tun`) молча потеряется.
- В mihomo `exclude-filter` применяется до `override`, так что префикс `[N]` фильтру не мешает.
  Регулярки в mihomo — regexp2 (синтаксис .NET), не Go regexp.
- В группе `proxy` не должно оказаться DIRECT/REJECT: иначе `url-test` выберет DIRECT как самый быстрый,
  и Claude тихо пойдёт мимо прокси. После правок групп проверяйте `/proxies/proxy` → `all`.

## Ядро и CI

- `mihomo.exe` — своя сборка с `patches\*.patch` из Releases `MKRED/mihomo` (теги `core-v<версия>`),
  собирает `.github/workflows/build-core.yml`. Пуш в `patches/**` или в сам workflow запускает пересборку.
- При смене версии WinSW добавьте её SHA-256 в `$WinswSha256` в `get-binaries.ps1`
  (в релизах WinSW сумм нет). Официальный mihomo сверяется по полю `digest` из API GitHub.
